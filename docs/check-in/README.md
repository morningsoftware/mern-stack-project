# Checkpoint check-in package

Read `readiness.md` first, then use `completion-plan.csv` and `rehearsal.md`.

Diagrams: gantt.mmd, activity.mmd, sequence.mmd, use-cases.mmd, class-diagram.mmd, erd.mmd. All are editable Mermaid text. `schema-dictionary.json` documents all 15 collections. The ERD is a logical application schema, not a declaration of MongoDB-enforced foreign keys. GitHub deliveries join by repository name; activity/resource IDs are polymorphic. Draft OpenAPI is at ../openapi.json.

Future Gantt dates are proposed estimates (November 9–19), not the official final deadline. Historical date ranges come from repository commits/merges. Assign named owners and align with the instructor's actual final date.

The editable PowerPoint and PDF are distributed separately; binary build outputs are intentionally not committed as application code.
