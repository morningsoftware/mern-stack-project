# Project activity

GET /api/activity?projectId=ID returns events, hasMore, and nextBefore. Team
membership/ownership is required. Optional before loads older pages (30 per page).
New task, milestone, build, bug, and feedback creations are recorded. Updates
record changes to title/name/version/status/priority/severity/assignee/milestone,
dueDate, or reviewStatus. Description-only edits are not tracked. There is no
historical backfill, delete log, client-write endpoint, or tamper-proof audit claim.

Actors/timestamps and selected before/after values are generated by the server;
comment bodies, image bytes, secrets, and download URLs are excluded. The UI offers
refresh and older pages. The feed is not a live subscription.

Primary records and activity are separate MongoDB writes. If recording fails,
the successful primary mutation stays successful, the server logs a warning, and
X-Checkpoint-Activity: unavailable appears on its response. History may therefore
have gaps after infrastructure failures; this is an operational feed, not a
transactional compliance ledger. Indexes are created at startup.
